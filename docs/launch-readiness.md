## 초기 사용자 부족 대응

전국 동시 출시보다 1~2개 넓은 생활권의 자발적 러닝 커뮤니티 파일럿으로 시작한다. 앱은 실제 조건을 만족한 후보만 표시하며 임계값·개인정보 경계를 완화하지 않는다. 가짜 사람·인위적 친구·운영자 강제 인증을 실제 사용자 경험으로 제시하지 않는다. 파일럿에서는 첫 주 완료율, 후보 없음 비율, 실제 상호 수락률, 신고/차단, 7일 재방문을 최소 집계로 확인한 뒤 지역을 넓힌다. 참가자의 정확한 경로/시각은 모집자나 상대에게 제공하지 않는다.
